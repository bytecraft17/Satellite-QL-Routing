# Satellite Network Routing using Q-Learning

NIT Delhi Summer Internship 2024

Implements QLRA and SQLRA algorithms from:
> Yin et al. (2021) — Reinforcement Learning-Based Routing in STINs

## Files
- `satellite_routing.py` — Main script
- `Satellite_QL_Routing.ipynb` — Jupyter Notebook
- `data1/2/3.xlsx` — Dataset (66-satellite constellation)

## Run
pip install networkx pandas openpyxl numpy matplotlib
python satellite_routing.py
